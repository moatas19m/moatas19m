### 🚀 Things I've built

**🗺️ [LandTeller](https://landteller.com)** — a geospatial platform that turns multi-gigabyte AutoCAD & shapefile drawings into interactive Mapbox maps. I re-architected its processing pipeline into an event-driven AWS system (Step Functions → S3 → EventBridge → SQS → Lambda) and **cut end-to-end latency by 77%**. Lived inside GDAL/ODA, GeoJSON, WGS84, and even ported a C++ SDK into native C# to debug it properly.

**🤖 Production RAG agent + MCP server** *(at Folio3)* — a retrieval-augmented assistant with a custom Model Context Protocol server (FastMCP) that lets **700+ colleagues** query internal knowledge and take actions in plain English. Also introduced AI-assisted code review to my team (~35% faster PRs).

**🧠 [Recruit Ranks](https://github.com/UsmanTirmizi/RecruitRankFYP)** — my final-year thesis: an NLP system that scores how well a CV matches a job description. It fuses embedding similarity with a **cross-provider LLM debate** (ChatGPT vs Gemini, judged by a third LLM) to produce an explainable 0–100 fit score. LLM-as-judge before it was cool.

**⚽ Khelgah** — a multi-tenant sports-booking platform (NestJS/Fastify + React Native + PostgreSQL) using Redis hold-locks to prevent double-bookings under concurrent load.

**🔬 [GRC Automaton](https://github.com/moatas19m/grc-automaton)** — an experiment in autonomous agents: I forked an agent framework to test whether an LLM could operate unsupervised, and built the guardrails and eval loops to watch *how* it fails.

...plus assorted curiosities on this profile — a [terminal AI tool](https://github.com/moatas19m/terminal-ai), an [MCP agent](https://github.com/moatas19m/mcp-agent), a [Mapbox/GeoJSON demo](https://github.com/moatas19m/mapbox-geojson-demo), a Django+Vue social app, and a [single-cycle RISC-V CPU](https://github.com/moatas19m/RISC-V_single-cycle-CPU) from my hardware days.
